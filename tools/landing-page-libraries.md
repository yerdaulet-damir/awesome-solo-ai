# Landing Page Component Libraries and Registries

Use this comparison when you already know what the page should show and need a component, interaction or section to implement it. For references, frameworks, typography and agent skills, start with the [frontend design resource guide](../guides/cinematic-frontend-not-slop.md).

Updated 16 October 2026.

## Choose by task

| Task | Resources | What you still own |
| --- | --- | --- |
| Style accessible interactive controls yourself | [Radix Primitives](https://www.radix-ui.com/primitives/docs), [Base UI](https://base-ui.com/react/overview/about) | Layout, visual styling and testing the composed interaction |
| Bring component source into a React project | [shadcn/ui](https://ui.shadcn.com/docs) | Updates, adaptations and review of third-party registry code |
| Find a visual component with a preview | [21st.dev](https://21st.dev/), [React Bits](https://www.reactbits.dev/) | Checking the selected component's dependencies and terms |
| Add a focused animated interaction | [Motion Primitives](https://motion-primitives.com/), [Magic UI](https://magicui.design/docs) | Timing, reduced-motion behavior and whether the effect suits the page |
| Start a marketing section from existing markup | [Tailark](https://tailark.com/docs), [HyperUI](https://hyperui.dev/) | Real copy, image direction, spacing and mobile composition |
| Explore effect-led React sections | [Aceternity UI](https://ui.aceternity.com/) | Selecting a useful effect rather than combining every demo |
| Build forms or an application surface | [Origin UI](https://originui.com/), [Park UI](https://park-ui.com/docs/introduction) | Error states, keyboard use and integration with the product |
| Buy established sections or templates | [Tailwind Plus](https://tailwindcss.com/plus) | Commercial license, customization and delivery to the client |

## Source code and commercial access

- shadcn/ui, Radix, Base UI, Magic UI, HyperUI, Origin UI, Park UI and Motion Primitives publish component source. Follow the license in the particular repository or registry item you use; a community registry is not covered automatically by another project's license.
- [React Bits](https://github.com/DavidHDev/react-bits) uses MIT + Commons Clause terms. Check those terms rather than treating it as plain MIT.
- Tailark and Aceternity have separate free and paid offerings. Tailwind Plus is commercial. A free preview is not permission to redistribute a paid template.
- 21st.dev is a discovery catalog with an [agent/MCP interface](https://21st.dev/mcp). Catalog use, installations and generation have different access limits; inspect the selected component as well as the service plan.

## Before copying a component

Read the source, check dependencies, replace the demo copy and assets, and verify keyboard and small-screen behavior. Keep interaction states consistent with the rest of the page. A decorative demo can be useful without becoming the visual system for the whole site.
